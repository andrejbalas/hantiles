# Sources

`search_index.json` is generated by `build_search_index.py` from:

| Data | Source | License |
| --- | --- | --- |
| Characters, fallback readings and definitions | [Make Me a Hanzi](https://github.com/skishore/makemeahanzi) `dictionary.txt` (derived from Unihan and CJKlib) | LGPL 3.0 or later |
| HSK 2.0 + 3.0 words, frequency ranks | [Complete HSK Vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary) | MIT |
| English meanings, extra words | [CC-CEDICT](https://cc-cedict.org/wiki/) | CC BY-SA 4.0 |

No word-frequency lists with non-commercial terms (SUBTLEX-CH, Leiden, Jun Da) are used.
Words outside the HSK lists get an estimated rank from their characters' ranks.

## Rebuilding

```sh
git clone --depth 1 https://github.com/skishore/makemeahanzi
git clone --depth 1 https://github.com/drkameleon/complete-hsk-vocabulary
# CC-CEDICT: download cedict_1_0_ts_utf-8_mdbg.txt from https://www.mdbg.net/chinese/dictionary?page=cc-cedict
python3 build_search_index.py makemeahanzi/dictionary.txt \
    complete-hsk-vocabulary/complete.json cedict_1_0_ts_utf-8_mdbg.txt \
    search_index.json
```

The result depends on the versions of the sources you download, so it can differ
slightly from the published `search_index.json`.
